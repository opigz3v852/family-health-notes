# 梁建章：杭州的育儿补贴可以推广吗？

> 更新时间：2026-09-16 (UTC+8)

近日，杭州市卫健委发布《杭州市育儿补助实施办法(试行)》规定，**此次补助类型和形式分为孕产补助和育儿补助两类，采用一次性发放现金形式。**孕产补助标准为：怀孕（生产）二孩给予一次性补助2000元，怀孕（生产）三孩给予一次性补助5000元。育儿补助标准为：生育二孩给予一次性补助5000元，生育三孩给予一次性补助20000元。补助对象为同一对夫妻自2023年1月1日起生育二孩、三孩的家庭，且新出生子女户籍登记在杭州。

杭州出台育儿补贴政策的背景，是近几年杭州出生人口不断下降。根据《2022年杭州市统计年鉴》的数据，2017年杭州户籍出生人口为10.95万人，2018年下降到9.47万人，2019年下降到9.15万人，2020年下降到7.98万人，2021年下降到7.16万人。

近年来，中国的出生人口和生育率不断下降。从2017至2022年，中**国出生人口已经连续六年下降，****2022年出生人口降至956万，只有2016年出生人口数1883万的一半左右。**低生育率的根源是生育成本过高，根据育娲人口发布的《中国生育成本报告2022》，中国的生育成本几乎是全球最高的。我们在以前的文章中已经多次提出关于降低生育成本的政策建议，其中包括发放育儿补贴。

到目前为止，国内已有多个地方政府先后出台育儿补贴政策。**与大多数已出台育儿补贴政策的城市相比，杭州育儿补贴的金额是比较高的**。例如，2022年10月长沙市卫健委、财政局印发的《关于发放三孩育儿补贴有关事项的通知》规定，对符合条件的家庭按其合法生育的第三孩及以上孩次每孩次一次性补贴1万元。又如，今年2月发布的《温州市户籍人口一次性生育补贴发放办法》征求意见稿拟规定，符合政策生育的夫妻，生育一孩的予以发放一次性生育补贴1000元，生育二孩补贴2000元，生育三孩补贴3000元。

杭州的育儿补贴金额之所以高于大多数城市，背后的原因是杭州雄厚的经济实力和财政收入。2022年，杭州GDP达到18753亿元，在全国各城市中排名第九位，按常住人口计算，全市人均GDP为15.26万元，而全国人均GDP为8.57万元。可见，杭州人均GDP远高于全国平均水平。2022年杭州市财政收入达到2450.6亿元，在全国各城市中排名第四位。

由于大多数城市并没有杭州市那样的财力，所以要推广类似杭州这样的补贴生育政策并不现实。而且，**虽然杭州的育儿补贴金额比多数城市更高，但相对于高昂的育儿成本来说，仍然是远远不够。**

我们认为，育儿补贴政策应该由中央层面出台更合适，一是因为大多数地方政府并没有足够的财力补贴生育，只有中央财政才有这个财力。二是因为人口是流动的，地方政府并不一定是出生率提高的受益者，孩子长大后有可能到外地工作，为整个国家做贡献但不一定是为本地做贡献。对于一个城市来说，要增加人口，通过吸引外来人口的方式比补贴生育更划算。例如，虽然近几年杭州出生人口不断下降，但常住人口不断增加，主要是因为有大量的外来人口流入。2022年杭州市常住人口比上年增加17.2万人，主要是依靠人口流入。但对于中国这样的人口大国来说，要保持人口规模优势，主要还是要依靠提高生育率，而不能指望引进外国移民。

那么，中国是否有钱来补贴生育呢？中国城市化和制造业的蓬勃发展，部分就得益于非常高的投资率。**未来中国的基建和工厂的建设需求趋于饱和，所以完全有能力从超额的用于固定资产的投资，拿出一部分来补贴生育。**

现在中国的人口老龄化还不是很严重，还有较高的储蓄和投资率，也就是说我们还有钱补贴生育。等到未来人口严重老化，2050年中国60岁以上老年人口比例将达到42.4%，65岁以上老年人口比例将达到32.5%，养老的财政负担加重，补贴生育的代价就会比现在高很多，所以现在补贴生育已经到了刻不容缓的时间节点。而且补贴生育是对未来人力资源的投入，长期有很好的回报。

2022年中国GDP达到121万亿元，如果拿出GDP的2%来补贴生育，约相当于2.4万亿元。按照平均每孩每月补贴1500元计算，即平均每孩每年补贴1.8万元。如果每年出生人口1000万，那么补贴当年出生人口需1800亿元。如果追溯到五年前的家庭，第一年的补贴金额可能需要9000亿元，以后逐步增加。法国和北欧国家等生育率较高的发达国家，每年拿出GDP的3%以上用于生育补贴等家庭福利开支。**中国的生育率要提升到发达国家的平均水平，需要拿出GDP的2%-3%来鼓励生育。**

总之，在出生人口不断下降的背景下，杭州出台育儿补贴政策的方向是正确的，但地方政府对于鼓励生育普遍是有心无力，需要在中央层面出台育儿补贴政策。因此，**要提升中国的生育率，国家**财政需要通过积极的货币政策来发放生育补贴。现在的中国经济正面临内需不足、消费疲软、产能过剩等问题，恰恰可以通过发放生育补贴来刺激经济，形成一举两得的效果。短期来说，补贴生育的福利支出有助于扩大内需、稳增长、稳就业。长期来看，有助于提升人力资源、人力资本、经济社会活力，增强中国经济发展的信心，提升中国的创新力和竞争力。
