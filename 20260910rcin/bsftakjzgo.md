# 15年慢性肾炎在38岁怀孕能坚持到生吗？

> 更新时间：2026-09-10 (UTC+8)

今年我已经38了，有15年的慢性肾炎史，之前因为这个病，我和老公基本上就都在避孕。本来都不打算生孩子了，结果上个月同房后，我的月经就一直没来，用早孕试纸一测，果然中招了，去医院验血确定怀孕了。我和我老公都舍不得打掉，因为他也是一条生命。但是我现在已经算是高龄了，而且还有肾炎，请问我这种情况如果停药的话，能坚持到生产吗？

一般情况下，对于大部分的肾炎患者来讲，都是可以生孩子的，但是都或多或少会损害肾功能。因为在怀孕期间，为了胎儿健康，大多数肾炎孕妇可能会停止服用治疗肾炎相关的药物，避免对胎儿造成影响，而且每个肾炎孕妇的实际情况不同，所以到底能不能坚持到生产也是两说。正常来讲，只要肾炎不急性发作，基本上就是可以生的。

肾炎是一种比较典型的肾脏疾病，主要是因为细菌感染引起的肾小球发生炎症。肾炎病情越严重，发生的并发症越多。肾炎是一种复杂性疾病，就算没有症状也不适宜怀孕。肾炎患者怀孕之后会出现以下几个影响。

- 1. 因为肾炎会导致母体免疫功能下降，肾功能下降，不利于胎儿发育，容易发生流产、早产或者死胎；
- 2. 并且肾炎很容易出现并发症，一旦出现重症感染，在治疗过程中需要大量使用抗生素，容易出现胎儿畸形；
- 3. 肾炎是一个复杂性疾病，会诱发肾功能衰竭，体内堆积大量毒素，会加重肾脏负担；
- 4. 就算勉强怀孕，在分娩时也会增加危险，最终形成不可逆转的伤害。

因此肾炎患者是不建议怀孕的，最好将肾炎疾病彻底治愈后，再考虑怀孕的问题。因为肾炎患者怀孕后，能不能坚持到生子是个问题，还有可能加重肾炎患者的病情。
目前来说治疗肾炎，最好的方法是采取抗生素，患者在用药期间要严格控制药物剂量，过量服用会增加肾脏负担。如果出现水肿比较严重，要限制盐的摄入量，防止出现中毒性反应。
